# TracePulse Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities to security@tracepulse.example.com

We will acknowledge receipt within 48 hours and provide a timeline for fixes.

## Security Measures

- End-to-end encryption for all device communications
- Secure pairing with challenge-response authentication
- Replay attack prevention with nonce tracking
- Message integrity verification using HMAC
- Session management with automatic expiry
